# ACE SIGN review page

Live at **https://acesign-au.github.io/review/**

- `review/` – cover → optional company name → Google review dialog. Each "Continue to Google" posts one record to the ACE SIGN Review Tracking API.
- `review/assistant/` – the earlier step-by-step review assistant (kept, not linked from the QR code).
- `/` redirects to `review/`.

The old address `hannahkuokuo.github.io/ace-sign-website/review/` redirects here, so printed QR codes keep working.
